# ContextNest dashboard

Sleek, dark-first dashboard for the ContextNest memory substrate. Vite + React 19 + Tailwind v4 + TanStack Router/Query + lucide icons.

See `../docs/ui/design-proposal.md` for the full design + IA. This package implements **Step 1: scaffold** — sidebar, six route stubs, brand tokens, substrate health badge, typed API client.

## Develop

```bash
cd web
pnpm install
pnpm dev
```

Dev server runs at `http://127.0.0.1:5057` (strict — won't pick a different port if taken). Point at your local substrate via `web/.env`:

```
VITE_API_BASE_URL=http://localhost:28080
```

If the substrate isn't running, the sidebar's health dot turns red and `/substrate` shows "Unreachable".

## Generated files

`src/routeTree.gen.ts` is generated by `@tanstack/router-plugin/vite` on first dev/build. It's in `.gitignore` — don't commit it. If you need it before running dev (e.g. for `pnpm typecheck`), run `pnpm dev` once and let it write the file, then ctrl-c.
